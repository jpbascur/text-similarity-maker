🔬 TSM — Text Similarity Maker

Generate embeddings of your documents' titles and abstracts, then use them to build a science map. Runs entirely in your browser using WebGPU — no data is sent to any server.

Built by Juan Pablo Bascur · Contact · GitHub · CPU fallback (Streamlit)

Step 1 — Text to Embeddings

Encodes each paper into a 768-dimensional vector using SPECTER2 (proximity adapter), running on your GPU via WebGPU. First run downloads ~210 MB of model weights — subsequent runs use the cached model.

If your browser does not support WebGPU, use the CPU fallback to generate embeddings, download the CSV, and upload it in Steps 2 or 3 below.

Requirements: CSV with columns id, title, abstract.

Transform file to supported format

Converts reference manager exports to the CSV format this app needs.
PubMed (.txt, .nbib) — Send to → File → Format: PubMed
RIS (.ris) — Scopus, Web of Science, Zotero, Mendeley, EndNote
BibTeX (.bib) — Google Scholar, Zotero, most reference managers

Step 3 — Embedding Space Reduction Map (UMAP)
